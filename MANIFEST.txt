SidwaOS 0.4.0
A minimal bootable x86 kernel: 3-state I/O machine, own two-stage
bootloader, .sidwa partition. Runs in QEMU.

Build:   make            (needs nasm, gcc -m32, ld, qemu-system-i386)
Run:     make run        (or: qemu-system-i386 -drive file=disk.img,
                          format=raw,if=ide,index=0 -serial stdio)
Test:    make check

disk.img is a ready-to-boot image, included so the system can be run
without building. `make` rebuilds it from source.
